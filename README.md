# 📝 Python Command-Line Text Editor

A simple, lightweight text editor that runs directly in the terminal. This project was built to practice core Python concepts like file handling, error management, and user input validation.

## ✨ Features
- **Create or Open:** Automatically checks if a file exists. If it does, it displays the current contents. If not, it creates a new one.
- **Multi-line Editing:** Allows the user to type as many lines of text as they want.
- **Safe Saving:** Type `SAVE` on a new line to securely write the text to the file and exit.
- **Crash-Proof:** Uses `try/except` blocks to gracefully handle missing files without crashing.

## 🚀 How to Run
1. Ensure you have Python 3 installed.
2. Clone this repository or download the `editor.py` file.
3. Open your terminal or command prompt.
4. Navigate to the folder and run:
   ```bash
   python editor.py
